# Repeat-Value and Ethical Engagement

Use this reference only when repeated use genuinely improves the user's outcome.

## Repeat-value loop

Recurring need -> Timely cue -> Small useful action -> Meaningful outcome -> User-owned future value

The objective is not maximal attention. It is a dependable relationship between a recurring user need and a product that resolves it well.

## Recurring need

Ask:

- What situation causes the need?
- How frequently does it occur?
- Is it functional, emotional, social, or contextual?
- Does the product solve it materially better than the user's workaround?
- Would the user still value the behavior if no engagement metric existed?

If the underlying need is weak or rare, do not invent frequency.

## Timely cue

A cue can come from:

- the user's environment,
- a routine,
- a calendar or event,
- another person,
- an explicit reminder,
- an opted-in notification,
- a state change in the product.

A good cue is relevant, timely, permissioned, understandable, and easy to disable.

Avoid unsolicited attention capture, forced sharing, and manufactured urgency.

## Small useful action

When people fail to act, first inspect friction.

Common friction sources:

- time,
- money,
- physical effort,
- mental effort,
- uncertainty,
- social cost,
- unfamiliarity,
- excessive setup,
- poor defaults.

Reduce the largest friction source before increasing persuasion.

The first action should produce real value quickly.

## Meaningful outcome

The outcome should resolve the need that initiated the interaction.

Legitimate outcome types can include:

- useful social connection,
- relevant information,
- progress,
- completion,
- mastery,
- saved time,
- reduced uncertainty,
- increased control.

Do not add randomness merely to increase session length.

Use special caution when uncertain outcomes:

- resemble gambling,
- target minors or vulnerable users,
- hide odds or costs,
- undermine intentional stopping,
- create anxiety as the main reason to return.

## User-owned future value

Repeat use can improve future value through:

- preferences,
- saved content,
- history,
- configuration,
- learned skill,
- reputation,
- relationships,
- templates,
- automation,
- personalized defaults.

Good accumulated value:

- benefits the user directly,
- follows demonstrated value,
- reduces future effort,
- remains understandable,
- can be exported or deleted when appropriate.

Bad accumulated value:

- exists mainly to create switching pain,
- withholds user data,
- forces contact import,
- makes exit intentionally expensive,
- relies on sunk-cost pressure.

## Natural repeat-use test

Before adding retention mechanics, assess:

- need frequency,
- per-use utility,
- cue quality,
- action simplicity,
- outcome quality,
- future-value accumulation,
- user autonomy.

A weak need or weak utility is a product problem, not a notification problem.

## Behavioral validation

1. Define the meaningful value event.
2. Identify users who repeatedly reach it.
3. Study what they do differently.
4. Form a hypothesis about the helpful behavior.
5. Make that behavior easier for other users.
6. Measure whether user value, not just activity, improves.

Do not define success solely by time spent, sessions, notifications opened, or raw frequency.

## Ethical review

Before recommending any engagement mechanism, ask:

- Does it materially improve the user's outcome?
- Is consent meaningful?
- Is the mechanism understandable?
- Can the user stop, snooze, cancel, export, or delete easily?
- Are costs and consequences clear?
- Does it preserve autonomy?
- Would we describe it openly in a public product review?
- Does it remain acceptable if the user is tired, stressed, young, or otherwise vulnerable?

If the answer is weak, redesign the mechanism.

## Trust-first alternatives

Prefer:

- event-relevant opt-in reminders over notification spam,
- flexible progress over guilt-based streaks,
- real availability over fake scarcity,
- optional valuable sharing over forced invitations,
- natural stopping points over endless consumption,
- easy cancellation over retention traps,
- visible personalization controls over hidden manipulation.
